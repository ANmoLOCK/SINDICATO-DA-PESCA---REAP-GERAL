# Sindicato da Pesca — REAP

Controle de contribuição REAP dos associados do **Sinapesc**.

## Programa para notebook (recomendado)

Pasta **`sinapesc-desktop/`** — aplicação Windows (`.exe`) com integração didática ao Google Sheets.

- Leia: [`sinapesc-desktop/README.md`](sinapesc-desktop/README.md)
- Guia da API: [`sinapesc-desktop/docs/GOOGLE_SHEETS.md`](sinapesc-desktop/docs/GOOGLE_SHEETS.md)
- Gerar instalável: execute `sinapesc-desktop/build_exe.bat` no Windows

## Origem

O ZIP original era um app web Next.js. A lógica de Pessoas/REAP foi reformulada para desktop, mantendo a planilha Google como banco de dados.
